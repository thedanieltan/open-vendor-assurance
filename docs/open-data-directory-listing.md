## Title

OpenVA Public Vendor Assurance Source References

## One-line description

Free public-source-only metadata for vendor-published assurance reference URLs.

## Short description

OpenVA is a free public-source metadata dataset for vendor-published assurance source references. It records factual locator metadata for public URLs such as trust centers, privacy pages, security pages, data processing addenda, subprocessor lists, status pages, public certification references, AI/data terms, and related source references.

## Boundary

OpenVA is metadata-only and non-advisory. It does not certify, approve, score, monitor, assess, or advise on vendors and does not replace human review of source documents.
