# Non-Advisory Policy

OpenVA records source-bound factual metadata only.

It does not provide legal, compliance, procurement, audit, KYC, AML, privacy, security, vendor-risk, or regulatory advice.

## Prohibited conclusions

Contributors and automation must not state or imply that a vendor is:

- compliant;
- safe;
- secure enough;
- approved;
- certified, unless the record only describes a public source reference to a certification claim;
- adequate;
- suitable;
- recommended;
- low risk;
- legally sufficient;
- acceptable for a particular obligation, jurisdiction, framework, workload, or organization.

## Permitted factual wording

Use source-bound wording such as:

- "Vendor publishes a public page describing..."
- "The public source references..."
- "The source is a public DPA page..."
- "The record points to a public subprocessor list..."
- "The source was last observed at..."

## Evidence rule

Every structured claim must point to a public source reference, source access class, and provenance metadata once the schema layer is active.
