OpenVA for Google Sheets

Look up canonical, public-source assurance references for your vendors against an OpenVA catalogue, and write stable result columns back into this sheet.

1. Configure

OpenVA → Configure API endpoint — enter the HTTPS base URL of an OpenVA deployment that has public read access enabled. The URL is stored with this document. No API key is used or stored.

2. Test

OpenVA → Test API connection — confirms the endpoint and shows the catalogue snapshot it is serving.

3. Input columns

Row 1 must be a header row. At least one of these is needed per row:

  • vendor_name
  • domain
  • business_entity_name
  • registration_number

Common header variants (e.g. Vendor Name, website, legal name) are recognized.

4. Enrich

  • Enrich selected rows — processes the rows in your selection.
  • Enrich active sheet — processes every data row.

Output columns are written with the openva_ prefix and reused on later runs.

What is sent

Only the four identity fields above, per processed row. Sheet names, spreadsheet ids, formulas, notes, and your email are never sent. Nothing is persisted outside this spreadsheet.

Results are public-source references cached to the service's loaded catalogue snapshot. They are not advice, live verification, compliance approval, security certification, or a vendor-risk judgement. An unmatched vendor means no catalogue match was found — not that the vendor is unsafe or non-compliant.
