Resolver-first public UI

Resolve public vendor assurance sources.

OpenVA helps CISO, DPO, procurement, compliance, and agent workflows turn vendor names into public source packs: privacy notices, DPA pages, subprocessor lists, security pages, trust centers, and compliance references.

Resolve vendor sources Export source pack

No account required. Public-source metadata only.

Recommended first step

Start with a vendor list, choose the source types you need, and export a source pack for your own internal review workflow.

Important boundary. OpenVA resolves public-source metadata only. It does not approve, certify, score, recommend, or determine whether any vendor is compliant, secure, suitable, or legally adequate. Do not upload private agreements, SOC reports, credentials, customer evidence, or confidential vendor inventories.

Role-specific views

CISO, DPO, and procurement source-pack views

Use these views to choose public source types for a review workflow. The views do not decide whether a vendor is secure, compliant, legally adequate, suitable, approved, or recommended.

CISO view

Security source pack

Use when the question is: where are the vendor's public security and assurance references?

Requested source types
security_page, trust_center, compliance_page, vulnerability_disclosure, certification_reference
Output boundary
Public source URLs only; not a security conclusion, approval, or risk score.
DPO view

Privacy source pack

Use when the question is: where are the vendor's public privacy, DPA, transfer, and subprocessor references?

Requested source types
dpa, privacy_notice, subprocessors_list, data_transfer_terms, ai_data_terms
Output boundary
Public source URLs only; not a DPA adequacy finding, transfer assessment, or legal opinion.
Procurement view

Intake source pack

Use when the question is: what public references should be written back into the vendor intake workspace?

Requested source types
dpa, privacy_notice, security_page, trust_center, subprocessors_list
Output boundary
Public source URLs and ambiguity/missing-source notes only; not vendor approval or procurement recommendation.

Developer view

Observation Feed

This feed contains machine-generated public-source observations. It is separate from resolved source packs.

Observation events may indicate that a public source was fetched, redirected, unavailable, hash-changed, bot-protected, rate-limited, or flagged for review. Observation events are not vendor approval, risk findings, compliance conclusions, procurement recommendations, legal opinions, or materiality determinations.
