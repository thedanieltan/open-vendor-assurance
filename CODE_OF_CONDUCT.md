# Code of Conduct

This project expects evidence-led, respectful, and non-advisory collaboration.

Participants must not use issues, pull requests, discussions, or documentation to:

- provide legal or compliance advice;
- promote vendor approval or rejection conclusions;
- harass contributors;
- publish private or gated materials;
- make unsupported claims about vendors;
- use the project for spam, promotion, or off-topic disputes.

Maintainers may close, edit, or remove contributions that violate the project doctrine, public-source-only rule, or non-advisory policy.
